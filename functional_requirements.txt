1. Functional Requirements

1.1 User Management 
Requirement ID      Requirement Description 
    FR 1.1          Users can register, log in, and log out securely. 
    FR 1.2          Users can edit their personal details. 
    FR 1.3          Admin can view or delete user accounts. 
 
1.2 Product Management 
Requirement ID      Requirement Description 
    FR 2.1          Admin can add, edit, or delete products with multiple images. 
    FR 2.2          Users can view and search products by name or category. 
    FR 2.3          Products can have multiple images that users can view in a slider.
 
1.3 Variant & Category Management 
Requirement ID      Requirement Description 
    FR 3.1          Admin can manage product variants (name, price, stock, image). 
    FR 3.2          Admin can add, edit, or delete product categories. 
    FR 3.3          Users can browse products by category. 
    FR 3.4          Each variant can have its own image that users can click to view.
 
1.4 Cart & Order Management 
Requirement ID      Requirement Description 
    FR 4.1          Users can add, update, or remove items from the cart. 
    FR 4.2          Users can place, edit, or cancel orders. 
    FR 4.3          Admin can update order details and track status.

1.5 Payment & Reports 
Requirement ID      Requirement Description 
    FR 5.1          Users can select a payment method (e.g., COD, GCash, card). 
    FR 5.2          Update order status (Completed, Ongoing, Canceled).

1.6 Search & Validation 
Requirement ID      Requirement Description 
    FR 6.1          Users can search and filter products easily from navigation. 
    FR 6.2          System validates inputs and prevent duplicates 

1.7 Ratings and Feedback 
Requirement ID      Requirement Description 
    FR 7.1          Allow customers to submit ratings and comments.
